# Contributing to roc-pdf

Start with the [contributor guides](development/README.md) for setup, testing,
resource-baseline review, documentation and release procedures. Read
[AGENTS.md](AGENTS.md), [architecture.md](architecture.md) and the
[capability requirements](feature-roadmap.md) before changing package behavior.

Keep changes focused and explain their user-visible effect. Documentation follows
[the current-reader rule](development/README.md#write-documentation).
