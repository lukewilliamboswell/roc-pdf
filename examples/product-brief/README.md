# Product brief

Run `roc main.roc` in this directory to write `product-brief.pdf`. The app
registers the included static Inter faces and sets `theme.latin_shaping:
InterLatin`. The 131 pt decision-workflow frame fits `AV Proposed -> Decided`
on its first line and puts `→ Archived` on its second line. With
`NominalGlyphs`, the first line breaks before `Decided`. Copying the two
arrows returns their original spellings.
