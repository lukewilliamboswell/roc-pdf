# Hindi and Latin account statement

Run `roc main.roc` here to write `hindi-statement.pdf`.

Register packaged Inter Regular and the included IBM Plex Sans Devanagari
Regular. With those faces in an ordered policy, enable
`Theme.international_text: HindiLatin`. Use `Pdf.in_language("hi", ...)` for
Hindi inside a document with another language.

`वित्तीय विवरण` shows a pre-base dependent vowel and a conjunct.
`कृपया` shows a positioned below-base mark. The activity cell preserves
the logical text `प्रशिक्षण शुल्क IN-42`. Keep each grapheme in one inline span.
A style boundary inside a conjunct gives a located diagnostic.
