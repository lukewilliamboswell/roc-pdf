= roc-pdf 0.6.0

Install the tested package with Roc `nightly-2026-11-25-d5a4f1e`.

[source,roc]
----
pdf: "{package-url}",
----

Bundle SHA-256 is `{bundle-sha256}`.

== Drawing paths

Preparation reports `drawing.path_order` at the authored command and segment
when a line, curve, or close has no open subpath. Use
`Scene.PathBuilder.move_to` to start each new subpath. A path with no
painting segment or an invalid rectangle dimension now returns a located
`drawing.path_geometry` diagnostic.

== Text diagnostics

* In ordinary flow, a figure caption with an unbreakable token wider than the
  available space reports `layout.unbreakable_token` at the caption. Add a
  line-break opportunity or increase the available flow width.
* Empty block links report `semantics.link_text_empty` at the link. Supply
  visible link text.
* A multi-scalar grapheme outside the simple furniture shaper's repertoire
  reports `text.unsupported_cluster` at the furniture item.

== Grayscale paint

`Color.gray8` and `Color.gray16` now work in text, drawings, page furniture,
and source foreground ranges. Both constructors specify neutral sRGB, with
the same output as three equal sRGB channel values.

== Layout and image diagnostics

Preparation identifies invalid theme values such as zero text leading or bullet
indent, negative paragraph spacing or page margins, and an underline that
exceeds its available space. Nonpositive fixed table widths, excessive
template gaps, and unrepresentable packed image row strides also return
diagnostics at the authored field.
