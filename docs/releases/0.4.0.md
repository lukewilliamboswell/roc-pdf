# roc-pdf 0.4.0

This release moves to a newer compiler compatibility boundary and reduces
font-processing work.
Existing authoring calls, supported document features and conformance profiles
are unchanged.

Use the tested package bundle:

```roc
pdf: "{package-url}",
```

Bundle SHA-256: `{bundle-sha256}`.

The package compiler is `nightly-2026-11-18-a520eed`; the Unicode dependency is
4.3.3. Upgrade the compiler alongside the package. The previous package and its
Unicode dependency do not compile under the new compiler, so the package and
compiler pins must move together. Existing authoring calls need no migration.
The runnable examples use basic-cli 0.28.1 to match this compiler's nominal-type
rules. Development builds can retain the previous lowering behavior with
`--opt=dev --specialize=yes`; the repository's measurement scripts pin it
explicitly.

Built-in font inspection reuses validated facts, font subsetting traverses
validated Unicode mappings once, and document identities use Roc's SHA-256
builtin. Font checksums preserve their wrapping arithmetic and table padding.
