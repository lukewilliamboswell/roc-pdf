# roc-pdf 0.1.0-rc4

This candidate adds preformatted source blocks with page continuation and independent running-text typography, and fixes custom-block defaults and repeated rich-text lines.

## Changes since rc3

- `Pdf.source_block` preserves indentation, trailing spaces and blank lines; handles CRLF and explicit tab policies; and uses its own registered face, size, leading and color. Measured wrapping retains long URLs and tokens under the selected policy. Blocks continue at visual-line boundaries, with padding and optional artifact backgrounds on every fragment. `Unsplittable` remains available with located fit errors. Preparation reports expose accepted fragment geometry and line ranges.
- `Theme.furniture: Own(...)` selects independent face, size, leading and color for headers, footers and page fields. The default still inherits the current body style. Field and region overflow remain explicit errors.
- Custom blocks accept their documented empty-panel and zero-inset defaults, with existing positive-size, drawing and fit checks retained.
- Equal adjacent rich-text segments retain their explicit line breaks through shaping, line layout and pagination, including code, spaces, multi-leaf segments and ordered multi-face text.
- Font options reject before unnecessary authoring normalization.
- The gallery now includes source continuation and independent furniture typography examples.

## Using the candidate

Use Roc `nightly-2026-10-14-38a3029`. Add the package to your application header:

```roc
pdf: "https://github.com/lukewilliamboswell/roc-pdf/releases/download/0.1.0-rc4/HqPLkg6Hn5wj4TKdQbrmRALzRQqWM2GbrZDN1t1oRn1D.tar.zst",
```

Bundle SHA-256: `a990d48300982bfa085735b97454a7df288eec03c24644bc3e89cd4d0a607c6e`.

The public `Pdf` facade remains the primary API.

Existing default furniture typography is preserved. To use source blocks, register a covering monospace face, pass its face ID to `Pdf.source_block`, and supply the registry through `Pdf.Options.fonts`. Source faces use `StyleFaces`; ordered policies reject with a located diagnostic. Source blocks default to 9/12 pt, four-column tab expansion, measured wrapping and line continuation.

See the [authoring guide](https://github.com/lukewilliamboswell/roc-pdf/blob/07f71fb1090efc22757a9c1ac3fee17bbea90dfa/docs/authoring.md), [source example](https://github.com/lukewilliamboswell/roc-pdf/blob/07f71fb1090efc22757a9c1ac3fee17bbea90dfa/examples/source-blocks/main.roc) and [furniture example](https://github.com/lukewilliamboswell/roc-pdf/blob/07f71fb1090efc22757a9c1ac3fee17bbea90dfa/examples/furniture-typography/main.roc).

## Scope

Default `Archive` output continues to claim static PDF/A-4 (`Pdf20 + StaticPdfA4`) for the supported subset. PDF/UA-2 is not claimed and `AccessibleArchive` remains unavailable. This is a pure Roc generation-only package; unsupported requests return typed errors without fallback output or profile downgrade. Source blocks continue across pages; other custom blocks remain unsplittable.
