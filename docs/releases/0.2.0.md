# roc-pdf 0.2.0

This release adds authored contents entries with a common right-aligned
page-number column, wrapped titles and optional decorative dotted leaders.
It also adds an optional Inter and Fira Code preset for body, heading, strong,
inline-code and source-code text, including the Command symbol (U+2318). Existing
destination references, links and PDF generation APIs remain available.

Use Roc [`nightly-2026-10-28-bad769b`](https://github.com/roc-lang/nightlies/releases/tag/nightly-2026-10-28-bad769b).
Add this immutable package to your application header:

```roc
pdf: "https://github.com/lukewilliamboswell/roc-pdf/releases/download/0.2.0/2hTpvYoKFHy8C6VeEgiv4FgWkP4oNTVupc1XCN8UwdiZ.tar.zst",
```

Bundle SHA-256: `f6c7120f4370bd185f4d83ebc4906f926a7fc724bfeb2ba30544263df27d26d0`.

Then use:

```roc
Pdf.contents_entry({
    title: [Pdf.strong([Pdf.text("Getting started")])],
    reference: { destination: "getting-started", width: 32 },
    indent: 18,
    leader: Dots,
})
```

Both title and number are internal links. Every title line reserves the page
column and gap before pagination; the exact resolved destination page appears
beside the final title line. Entries can continue across pages. Dotted leaders
are geometric page artifacts and add no dots to extracted text or reading order.

This is a bounded layout primitive. Applications still collect headings, choose
entries, assign ancestry and create their destinations. It does not add automatic
contents generation, indexes or a new conformance claim. The default Archive
profile remains tagged PDF 2.0 with the existing static PDF/A-4 claim.

The [destination-reference guide](../destination-page-references.md) describes
properties and rejection behavior. Existing facade users can upgrade their
package URL without changing their authored documents.

## Inter and Fira Code

Register the packaged static instances once and reuse their registry:

```roc
faces = RocFont.register(Font.Registry.empty, Font.ValidationLimits.default)?
options : Pdf.Options
options = {
    fonts: Registered(faces.registry),
    theme: RocFont.theme(faces, {}),
}
```

Use `faces.source_code` for source blocks. The preset provides Inter Regular
and Bold at optical size 14 and Fira Code Regular. Emphasis inherits its face;
applications can register genuine italics or other custom fonts. Missing glyphs
remain errors, and Latin shaping is the supported boundary. This adds no runtime
variable-font or automatic serif fallback support.

The [font preset guide](../roc-font.md) covers role choices, reuse and licenses.
The default theme is unchanged. Applications with explicit font registration
must select the preset to adopt it; changing faces can change line breaks and
pagination. Both font families ship with their OFL notices.
