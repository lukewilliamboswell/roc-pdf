# roc-pdf 0.1.0-rc2

rc2 adds prepare-once output, sRGB theme colors, and image figures.

Highlights:

- Opaque `Pdf.Prepared` values can be emitted as buffered bytes or chunks.
- Theme colors support exact 16-bit sRGB and convenient 8-bit channels.
- Theme setters configure text styles, spacing, and margins.
- Figures accept typed packed-raster or validated JPEG images, with required
  alternative text and optional captions.
- Unsupported requests return bounded `InvalidDocument` diagnostics with
  stable dotted feature codes.
- Runnable examples and generated API documentation show the public API.

These notes describe rc2. Its output uses the `Standard` PDF 2.0 profile;
PDF/A-4 and PDF/UA-2 are unavailable. Single-image figures are supported in
this version. Broader drawings and fixed pages can be authored, but
preparation rejects them without emitting output.

See [the migration guide](../migrating-to-rc2.md) and
[authoring guide](../authoring.md). The [rc3 notes](0.1.0-rc3.md) describe the
later Archive default and expanded authoring support.
