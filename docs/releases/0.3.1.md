# roc-pdf 0.3.1

This release updates compiler compatibility and reduces font-processing work.
The public authoring API, supported document features and conformance profiles
are unchanged.

Use the tested package bundle:

```roc
pdf: "{package-url}",
```

Bundle SHA-256: `{bundle-sha256}`.

The package compiler is `nightly-2026-11-18-a520eed`; the Unicode dependency is
4.3.3. Upgrade the compiler alongside the package. Existing authoring calls need
no migration.

Built-in font inspection reuses validated facts, font subsetting traverses
validated Unicode mappings once, and document identities use Roc's SHA-256
builtin. Font checksums preserve their wrapping arithmetic and table padding.
