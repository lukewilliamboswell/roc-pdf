# roc-pdf 0.2.0-rc1

This release candidate adds authored contents entries with a common right-aligned
page-number column, wrapped titles and optional decorative dotted leaders.
Existing destination references, links and PDF generation APIs remain available.

Use Roc [`nightly-2026-10-27-de79a0f`](https://github.com/roc-lang/nightlies/releases/tag/nightly-2026-10-27-de79a0f).
Add this immutable package to your application header:

```roc
pdf: "https://github.com/lukewilliamboswell/roc-pdf/releases/download/0.2.0-rc1/J3ssr9CQcBBnd66d7677qWM3AJwvdaHMN3RbHp75VpPa.tar.zst",
```

Bundle SHA-256: `109ec4aaffee53486f72d9ebb61dd77911249c3ce981a68391e594d77186ce52`.

Then use:

```roc
Pdf.contents_entry({
    title: [Pdf.strong([Pdf.text("Getting started")])],
    reference: { destination: "getting-started", width: 32 },
    indent: 18,
    leader: Dots,
})
```

Both title and number are internal links. Every title line reserves the page
column and gap before pagination; the exact resolved destination page appears
beside the final title line. Entries can continue across pages. Dotted leaders
are geometric page artifacts and add no dots to extracted text or reading order.

This is a bounded layout primitive. Applications still collect headings, choose
entries, assign ancestry and create their destinations. It does not add automatic
contents generation, indexes or a new conformance claim. The default Archive
profile remains tagged PDF 2.0 with the existing static PDF/A-4 claim.

The [destination-reference guide](../destination-page-references.md) describes
properties and rejection behavior. Existing facade users can upgrade their
package URL without changing their authored documents.
