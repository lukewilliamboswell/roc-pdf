# 0.1.0-rc1 consumer smoke test

## Purpose

This records the manual consumer smoke test performed against the published
0.1.0-rc1 release bundle. It compiles a small `basic-cli` application against
the served release URL — exactly what an external consumer does — rather than
against the local package sources. The source is preserved here instead of in
`examples/` because `scripts/test.py` compiles and tests every `examples/*.roc`
file, and this program requires network access to fetch the `basic-cli`
platform and the released `roc-pdf` bundle. Keeping it out of `examples/`
keeps the test driver fully network-free.

## Source

```roc
## Generate a small PDF using basic-cli and roc-pdf 0.1.0-rc1.
app [main!] {
	pf: platform "https://github.com/roc-lang/basic-cli/releases/download/0.21.0/4rAQg8kUYZ3Vksr4qMQHpaFYNiHSn9GgS7gVxghd1XYV.tar.zst",
	pdf: "https://github.com/lukewilliamboswell/roc-pdf/releases/download/0.1.0-rc1/5f2kc2B9MXvxB9uHeJQNJMZd9gbYHCAbRCgJfKcfjD2v.tar.zst",
}

import pf.OsStr
import pf.Path
import pf.Stdout
import pdf.Pdf

main! : List(OsStr) => Try({}, _)
main! = |_args| {
	document = Pdf.document({
		contents: [
			Pdf.title("My first Roc PDF"),
			Pdf.paragraph("This searchable PDF was generated by a pure Roc package."),
			Pdf.heading(1, "Available features"),
			Pdf.bullets([
				"Deterministic PDF 2.0 output",
				"Embedded searchable text",
				"Titles, headings, paragraphs, and lists",
				"A4 and Letter page sizes",
			]),
			Pdf.heading(2, "Release candidate"),
			Pdf.paragraph("roc-pdf is early software. This release supports the Standard profile; PDF/A-4 and PDF/UA-2 are not yet available."),
		],
		language: "en-AU",
		title: "My first Roc PDF",
	})

	options = Pdf.Options.with_page_size(Pdf.Options.default, Pdf.PageSize.A4)
	bytes = Pdf.to_bytes_with(document, options).map_err(|err| PdfGenerationFailed(err))?

	output : Path
	output = "example.pdf"
	output.write_bytes!(bytes).map_err(|err| FileWriteFailed(err))?

	Stdout.line!("Wrote example.pdf").map_err(|err| OutputFailed(err))?
	Ok({})
}
```

## Run instructions

1. Save the source above as `basic_cli_pdf.roc` in an empty directory (outside
   this repository, or anywhere `scripts/test.py` does not scan).
2. Build and run it with the repository's pinned official Roc nightly
   (`.roc-version` = `nightly-2026-08-08-195c9e7`):

   ```
   roc basic_cli_pdf.roc
   ```

   The first run fetches the `basic-cli` platform and the released `roc-pdf`
   bundle over the network.
3. Inspect the produced `example.pdf` in a viewer and confirm the text is
   selectable and searchable.
