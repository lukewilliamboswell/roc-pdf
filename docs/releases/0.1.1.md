# roc-pdf 0.1.1

roc-pdf is a pure Roc package for generating deterministic PDF 2.0 documents.
0.1.1 is a patch release for current Roc nightlies. Roc nightly 2026-10-24
added builtin types named `Range` and `Stream`, and roc-pdf 0.1.0 defines
types with those names, which the compiler now reports as warnings (so
`roc check` exits with its warning status). 0.1.1 renames them and builds
without warnings. Generated PDFs are unchanged.

## Using the release

Use Roc [`nightly-2026-10-25-72704da`](https://github.com/roc-lang/nightlies/releases/tag/nightly-2026-10-25-72704da). Add the
package to your application header:

```roc
pdf: "https://github.com/lukewilliamboswell/roc-pdf/releases/download/0.1.1/74vCqoe79STiSdqyfE5FGTjaETWTnZbmNEVNbbKb9kyB.tar.zst",
```

Bundle SHA-256: `f9e160758e9ebd59a0c72f620e51ae7d2bc49c74f6bb8c0a9d7b637b26eda423`.

Import `pdf.Pdf` and start with the [authoring guide](../authoring.md) and the
[example gallery](../../examples/README.md). Everything 0.1.0 supports is
described in the [0.1.0 release notes](0.1.0.md).

## Changes since 0.1.0

- `Semantics.Range` is renamed `Semantics.IndexRange`: a contiguous run of
  `length` indices beginning at `start` into one of the semantic model's
  dense buffers. Its constructor and fields are unchanged.
- Depends on `unicode` 4.3.1, which renames its own internal `Stream` type
  for the same reason; 4.3.0 warned on these nightlies too.
- Built and tested with Roc `nightly-2026-10-25-72704da`, with no compiler warnings.
- Output bytes, text, structure and metadata are identical to 0.1.0 for the
  same input.

## Upgrading from 0.1.0

Install the Roc nightly named above and update the package URL. Code that
names `Semantics.Range` must name `Semantics.IndexRange` instead; nothing
else changes. Code that uses only the `Pdf` facade compiles unchanged.
