# roc-pdf 0.1.0-rc6

This candidate adds technical-manual authoring: printed destination page numbers,
chapter-specific headers and opening pages, rich numbered instructions, and
callouts that continue across pages.

## Changes since rc5

- `Pdf.page_reference` prints the page of a named destination in a reserved-width
  box. Choose physical page numbers or configured page labels; wrap it in an
  internal link when you want a clickable number. `Pdf.page_label` displays
  configured labels in headers and footers.
- `Pdf.page_scope` gives chapters separate opening and continuation templates,
  with an explicit running label displayed through `Pdf.running_label`.
- List items can keep source blocks, captioned figures, tables and nested
  callouts inside the same numbered instruction as it continues across pages.
- `Pdf.callout` calculates its height from its contents and repeats its panel
  and padding on each page fragment. Measured `Pdf.custom_block` extensions
  retain their existing unsplittable behavior.
- The prepared vector-diagram example converts a constrained Mermaid/SVG
  subset to public Roc drawings with searchable text. It rejects embedded HTML
  labels and unsupported SVG features. Preparation is separate from PDF generation.
- Decorated tables reserve their full painted extent, keeping fills and rules
  inside the page body, including beneath repeated headers.
- User guides now focus on usage, supported behavior and migration.

## Upgrading

Existing facade calls remain supported. Corrected table positioning can change
page breaks and PDF bytes; review expected PDFs when upgrading.

Advanced exhaustive matches must handle `Callout` and `PageScope` in
`Document.Block`; `PageReference`, `PageLabel` and `RunningLabel` in
`Document.Inline`; and `CalloutFragmentPlaced` and `PageScopeApplied` in
`Pdf.ReportOutcome`.

The default remains `Archive` (tagged PDF 2.0 with static PDF/A-4). PDF/UA-2 is
not claimed, and `AccessibleArchive` remains unavailable. Unsupported requests
return located errors without profile downgrade or font substitution.
