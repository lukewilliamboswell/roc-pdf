# roc-pdf 0.5.0

Use this package with Roc `nightly-2026-11-23-b5c77fc`. Upgrade the
compiler and the package URL together. The previous bundle can stall on
this compiler while lowering defaulted records. Existing PDF authoring
calls carry over.

The document builder now reports `semantics.heading_level` for destination
headings outside levels 1–6, matching the block-based API.

```roc
pdf: "{package-url}",
```

Bundle SHA-256 `{bundle-sha256}`.
