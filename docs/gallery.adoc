[#runnable-document-gallery]
= Runnable document gallery

These complete applications use public Roc APIs. Run one from a checkout to
inspect its PDF and then adapt its source to your own content.

Use the compiler pinned in the checkout and run the application from its
directory. For example:

[source,sh]
----
cd examples/product-brief
roc run main.roc
----

The application writes its PDF in that directory. The committed preview
shows a selected page rendered at 96 dpi. To use an example with a published
package, point its `pdf` dependency at the release bundle.

[#quarterly-financial-schedule]
== Quarterly financial schedule

In the results-by-segment table, one revenue heading covers both quarters and
one Farm operations header covers the Grain and Farm supplies rows. The
Grain result of AUD 3,262 thousand names Q2, Revenue, Grain and fodder, and
Farm operations explicitly. Farm supplies uses its scope-derived
associations. The two farm rows stay together.

https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/main.roc[Runnable quarterly report source] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/quarterly-report.pdf[PDF output] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/preview.png[Page-two preview]

Run `roc run main.roc regional` from `examples/quarterly-report` for a
two-page regional commentary. One spanning cell holds the sixteen
observations and retains its three header references across both pages.
The repeated headings are artifacts. `regional-keep` rejects the same
schedule with `layout.oversize_span_group` at both body rows.

[#designed-brief]
== Designed product brief

This US Letter opener gives the Sprout launch title, key figures, and a
captioned board illustration their own fixed frames. The order of the
`place` calls sets the reading order. `with_paint_order([2, 0, 1])`
paints the figure and its caption first, then the title and card.
The background and accents are artifacts.

https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/designed-brief/Brief.roc[Authored frames and order] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/designed-brief/main.roc[Runnable source] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/designed-brief/designed-brief.pdf[PDF] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/designed-brief/preview.png[Preview]
