== Hebrew and English invoice

The Hebrew address wraps after the city. The second line includes a
parenthesized purchase-order ID. The mixed service cell pairs a Hebrew
description with the selectable text `SKU-42 ILS 1,250.00`.

[#quarterly-financial-schedule]
== Quarterly financial schedule

In the results-by-segment table, one revenue heading covers both quarters and
one Farm operations header covers the Grain and Farm supplies rows. The
Grain result of AUD 3,262 thousand names Q2, Revenue, Grain and fodder, and
Farm operations explicitly. Farm supplies uses its scope-derived
associations. The two farm rows stay together.

https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/main.roc[Runnable quarterly report source] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/quarterly-report.pdf[PDF output] · https://github.com/lukewilliamboswell/roc-pdf/blob/main/examples/quarterly-report/preview.png[Preview]

[#service-intake]
== Service intake

The form has two editable text fields and two independent checkboxes.
Include an inspection report starts checked, and Request a site visit starts
unchecked. See the
