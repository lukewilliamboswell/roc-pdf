# Roc nightly 2026-08-16 bulk re-baseline

Date: 2026-08-17

## Decision

The package moves from `nightly-2026-08-08-195c9e7` (locally backed by the
patched `release-fast-64c9d73d` compiler) to the official
`nightly-2026-08-16-23452ea` release. The official nightly builds the complete
suite, including the packed-constant cases that blocked the earlier official
nightly, so the patched-compiler requirement is retired.

This is a compiler-only change. Package behavior, scenarios, deterministic
work counters, retention evidence, and PDF snapshots are unchanged.

## Controlled run

- Host and execution target: Linux x86_64, `x64musl`.
- Roc optimization: `dev`; Zig 0.16.0 host built with `ReleaseFast`.
- Measurement boundary: `before_fixture_main`.
- Official Linux x86_64 archive SHA-256:
  `e63af615dd121aa4ddb56dd0cb914e41d56c9d858ee8ecd40a96135d79ceb8c6`.
- Command: `./scripts/test.py --compare-baselines`, with `ROC` selecting the
  extracted official compiler.

The complete run passed package, evidence, fuzz-evidence, public-example,
snapshot, structural, retention, and deterministic-work checks. It reported
only the allocation decreases below. No allocation increase or functional
regression was observed.

## Allocation changes

| Scenario shape | Old | New | Delta |
| --- | ---: | ---: | ---: |
| Compact builder, 1,000 / 10,000 blocks | 102 / 127 | 97 / 122 | -5 / -5 |
| Semantic planning, 1,000 / 10,000 blocks | 238 / 269 | 233 / 264 | -5 / -5 |
| Batch shaping, 1,000 / 10,000 blocks | 258 / 289 | 253 / 284 | -5 / -5 |
| Cached line layout, 1,000 / 10,000 blocks | 294 / 325 | 289 / 320 | -5 / -5 |
| Row pagination, 1,000 / 10,000 blocks | 332 / 377 | 327 / 372 | -5 / -5 |
| Public multi-face facade, one document | 1711 | 1701 | -10 |
| Shared multi-face registry, two documents | 3350 | 3330 | -20 |
| Unique multi-face registries, two documents | 3419 | 3399 | -20 |

The first ten cases share one facade pipeline prefix and lose five fixed
allocations regardless of input scale. The multi-face cases execute the same
improved path twice per document, explaining their additive `-10` and `-20`
shifts. Unchanged work counters rule out skipped package work, and identical
PDF bytes rule out a behavior change. The decreases are accepted as one
toolchain-caused ownership/code-generation improvement.

The repository historically records identical dev-backend allocation counts
for `arm64mac` and `x64musl`. In keeping with this upgrade's pragmatic scope,
both baseline columns are updated atomically from the target-independent fixed
delta observed on `x64musl`; the next Apple Silicon CI run remains the direct
confirmation of that column. No timing or peak-RSS claim is made by this
upgrade.

## Harness compatibility

Current official nightly tags use a numeric month. The toolchain verifier now
accepts both numeric-month tags and the older month-name spelling, with self
tests for both forms and for matching `release-fast` commit identities.
