# Destination page references

## Representation review before implementation

Destination references are authored semantic inline leaves with an explicit
fixed advance. Their value remains symbolic until committed pagination supplies
the destination anchor page. No guessed Unicode, padding characters, font
substitution, or layout-dependent width participates in measurement.

The implementation preserves dense leaf and occurrence identities across rich
paragraphs, table cells and nested flow. Reference records own destination names
once; later relationships use dense indexes. Accepted pagination supplies the
same anchor facts to references and navigation. Final resolved Unicode is
validated and shaped in the inherited style and language before fragments,
navigation, subsetting and sealing. Page-label formatting is independent of
list-label formatting, bounded before allocation, and shared by references and
visible page-label furniture.

Large traversals must be linear in input, measured items and accepted fragments;
ordered-name lookup is bounded logarithmic work. Growing arenas are consumed
and reassigned without retaining an old record projection or error-path alias.
Measurements and scalar continuations retain no discarded page scenes or
source suffixes. Exact allocation/work evidence and independent PDF checks are
required before this record establishes feature closure.

This branch owns navigation/reference production changes and their focused
fixtures. Architecture and roadmap edits belong to the integration coordinator.
