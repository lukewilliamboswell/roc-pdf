= Linux desktop comparison evidence

The two Linux x86-64 runs used the same workload, font and harness on an
AMD Ryzen 7 9700X. The runs changed the Roc compiler and the package together.
Source-build and script timings use one observation per cache state.
Compiled execution uses a five-sample median. The archived record identifies
the exact source and tool versions, cache states, package optimization,
phase times and peak RSS.

The measured output contracts differ. Roc declares its explicit archival
profile and supplies tagged output and a color profile. The Go and Python
workloads produce ordinary PDFs. Optimization comparisons also include
changes in compression level. See the
https://github.com/lukewilliamboswell/roc-pdf/blob/8afbfeb55e6e5f4e4a31cc6c397c9ff22ce19b07/docs/contributors/benchmarks/pdf-comparison/results/linux-desktop-2026-10-20.md[immutable measurement record].
