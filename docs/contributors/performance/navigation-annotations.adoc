[#contributor-navigation-annotations]
= Navigation, annotations, and outline targets

Prepared navigation resolves authored target identity before object
lowering. A GoTo action writes a paired structure destination and geometric
destination from one resolved record. Keyboard order, page ownership, and
semantic order remain explicit and independently checked.

[#contributor-navigation-annotations-stage-contracts-and-representations]
== Stage contracts and representations

`KernelNavigation.resolve` follows each target's explicit anchor
occurrence to its first committed fragment. Its page and geometry
supply `/XYZ`; the authored target supplies `/SD`. A destination name
registry resolves one ordered UTF-8 key at a time by binary search.
A named target shares the paired facts. The `/D` plus `/SD` on an
internal GoTo comes directly from the resolved record.

A wrapped Link joins multiple active quads on one page into one
annotation and one OBJR for that page. Every annotation's explicit
`/StructParent` key, ParentTree owner, and `/Pg` agree. The active
regions use counterclockwise quads starting on their lower edge.
The annotation's `/Rect` encloses their union. Keyboard order follows
authored facts, and outline counts follow the authored hierarchy.
See ISO 32000-2 §12.3.2.3, §12.5.6.5 Table 176, §14.8.4.7.3 and its
resolved errata.

[#contributor-navigation-annotations-independent-evidence]
== Independent evidence

`scripts/check_navigation.py` parses the emitted bytes directly. It
checks keyboard-ordered `/Annots` references, the closed action union,
paired destinations and exact resolved coordinates, quad containment
and vertex order, ParentTree and OBJR ownership, name-tree keys and
limits, independently computed outline counts, ascending page-label
keys, and appearance geometry. Mutation twins exercise malformed
links, swapped coordinates and owners, missing keys, and duplicated
annotation references. Cases in `tests/spec.json` also pin facade
equivalence, destination reuse and negative authorship.

`scripts/check_navigation_renderers.py` drives the pinned reader matrix.
The `PdfBoxNavigate.java` lane checks real page resolution through
`/D` and through the name registry. This complements structure inspection
of `/SD`, which readers need for navigation using the structure tree.

[#contributor-navigation-annotations-combined-accessible-archive]
== Combined accessible archive

In the accessible archive control, two annotation objects and two
ParentTree keys resolve to one logical Link and one authored Overview
target. The named Results destination supplies a valid wrong-target
mutation. The checker also rejects replacing one fragment's action
with an external URI under the same Link owner. The profile control
verifies PDF/UA-2 identification separately from the navigation facts.

See https://github.com/lukewilliamboswell/roc-pdf/blob/a6d1bde3028d51955b96af3ba1a183855a92cd2d/docs/contributors/performance/navigation-annotations.md[the archived design and measurements].
