= Facade batch shaping

Count requests from the validated occurrence store before allocating request and run buffers. A request takes earlier source, style, face and occurrence facts. The bounded shaper checks cumulative source bytes, scalars, clusters and glyphs before producing shaped arenas. Immutable shaped templates may be shared across placements. Use the batch shaping scales to verify that request construction and write counts grow with their declared inputs.

Selected shaping validates each request against a cursor over the source's
ordered Unicode script runs. A group partitions its whole source in order,
so subsequent requests only examine runs their range reaches. A long script
run can cover several requests without being copied. The focused 16- and
8,192-run alternating cases inspect one script-run row per one-run request,
in addition to the group's single structural walk. The cursor resets for each
group, including repeated placements of the same source.

For an end-to-end scale pair, build `benchmarks/mixed_script.roc`. It uses the
receiving handover example's checked-in Han font. Run with `-n 64` and
`-n 4096`, passing `--max-source-script-runs 8192 --prepare-only` to both
runs. A single paragraph holds all alternating Latin and Han runs. Running
the larger case at the default script-run limit exercises the atomic
budget diagnostic.
