[#contributor-shadings-patterns]
= Shading and colored tiling pattern resources

Scene normalization validates linear or radial shadings and colored tiling
pattern cells. It derives deterministic function and resource identities
before object planning. Each consuming stream names its direct dependencies.

[#contributor-shadings-patterns-fixed-width-numeric-semantics]
== Fixed-width numeric semantics

* Stop offsets are public `U16`: 0 is domain 0.0, 65535 is domain 1.0,
`t = offset / 65535` exactly. The canonical PDF number is
`round_half_even(offset * 1000000000, 65535)` at scale 9 — byte-identical to the
channel and constant-alpha mapping, so stitch `/Bounds`, function
`/C0`/`/C1`, painted channels, and `/ca` all agree on one arithmetic.
* Stop colors are the existing `U16` channels under the same mapping.
* Coordinates, radii, steps, and matrices are `Layout.Unit` (`I64`
milli-points, 1000 per point) emitted at the exact scale-3 mapping `cm`
and `re` operands use. Negative zero is unrepresentable (`I64` raw), all
derived arithmetic is checked, and no host floating-point formatting
exists anywhere in the path.
* `/Domain [0 1]` and `/Encode [0 1 …]` are emitted explicitly as integers;
`/Extend` is always the explicit two-boolean array; radii must be
non-negative; pattern steps must be strictly positive; pattern matrices
must have a nonzero checked determinant.

[#contributor-shadings-patterns-function-object-strategy]
== Function-object strategy

The simplest faithful representation of the exact stop model: exponential
interpolation per stop interval with `/N 1`, stitched with the exact
interior offsets as bounds and canonical `[0 1]` encode pairs. Stop
ordering and domains validate at the scene boundary before object planning;
function objects have deterministic content-derived identity and canonical
ordering; equal functions merge only after exact recipe equality; every
referenced function is an explicit graph node and planned object; and
construction is bounded by the per-shading stop budget (256), the shared
recipe-byte budget, and the graph's resource/object limits. No function
language is public, and independent inspection re-derives domains, bounds,
encode arrays, endpoint components, and adjacent-segment continuity from
the emitted objects alone.

[#contributor-shadings-patterns-resource-dag-and-closure]
== Resource DAG and closure

Shadings depend on their color space and root function. A stitching
function depends on its segments. Pattern cells declare direct image,
form, opacity-free paint, and shading resources. Graph closure includes
the function objects without adding entries to stream dictionaries.
A reversed topological pass marks pattern-reachable forms and validates
transitive restrictions over direct edges.

[#contributor-shadings-patterns-object-planning-lowering-and-emission]
== Object planning, lowering, and emission

Shadings use Type 2 or 3 dictionaries. The paint operator is `sh` with
the canonical shading name. Uncolored tiling patterns are outside this
API. A colored cell emits one `/PaintType 1 /PatternType 1` stream and
uses `/Pattern cs` plus the canonical `scn` selection. The checked
matrix maps pattern space into the default space of its consuming stream.
Transformation follows ISO 32000-2 §8.7.3.1.

[#contributor-shadings-patterns-independent-evidence]
== Independent evidence

`scripts/check_shadings.py` validates exact dictionaries and operators,
function domains and continuity, direct resource reachability, canonical
sharing, and mutation rejections. `scripts/check_shading_renderers.py`
compares generated rasters to independent geometry and color models.
The `shadings-patterns-v1` cases in `tests/spec.json` pin scaled sharing,
distinct recipes, geometry, limits, and malformed atomic cases.
