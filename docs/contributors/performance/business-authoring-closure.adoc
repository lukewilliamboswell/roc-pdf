= Business authoring checks

The invoice, report and letter are authored through the public APIs.
Their accepted layouts, rejections and scale variants are recorded in
xref:contributor-reference.adoc#contributor-reference-documents[the reference document contract]
and in the
https://github.com/lukewilliamboswell/roc-pdf/blob/main/tests/spec.json[fixture inventory].
The gallery verifies regeneration from both the checkout and the published
package bundle. The negative paths check located errors before any bytes or
chunks are available.

The ordinary fixtures validate the default combined PDF/A-4 and PDF/UA-2
declarations. The structure checks cover metadata title and display,
standard roles and namespaces, authored table header identity, marked content,
artifacts, and geometric and structure destinations. The project decoder and
optional PDFBox extraction provide independent observations of structure.
Compare values with the authored fixture to detect substitutions that still
satisfy a generic file validator.

The scale cases retain output identity, exact allocation counts and work
counters. See xref:testing.adoc[Testing roc-pdf] for the baseline protocol and
xref:contributor-conformance.adoc#contributor-static-pdfa4[static archival checks]
for the supported writer policy. Implementation history and before/after
measurements are in the
https://github.com/lukewilliamboswell/roc-pdf/blob/8afbfeb55e6e5f4e4a31cc6c397c9ff22ce19b07/docs/contributors/performance/business-authoring-closure.md[previous evidence record].
