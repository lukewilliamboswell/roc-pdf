= Optional Arlington object-model review

Arlington checks PDF object relationships derived from ISO 32000-2:2020. Its
scope excludes lexical syntax, content-stream operators and file layout. The
project-owned byte and structure checkers cover the supported output in CI.

For local review, start the service at the version expected by the report
parser and invoke the checker on a generated file.

[source,sh]
----
docker run --rm -p 127.0.0.1:18080:8080 \
  verapdf/arlington@sha256:1543368902c393771557e2a1da69e64ad72b69db32e6efebd38a09a7b86eacbc
python3 scripts/check_arlington.py output.pdf
----

Run the second command in another shell. `--cases` selects registered fixtures
and examples. The checker verifies the service version, selected `arlington2.0`
profile, parser status, file length, and reported findings on the original
bytes. `--self-test` exercises the report parser offline.
