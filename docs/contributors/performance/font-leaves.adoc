= Canonical font leaves

Canonical identity covers one complete nine-object font bundle. The subset program, CID map, widths, descriptor and ToUnicode stream derive from one validated face and glyph plan. The canonical recipe includes the schema tag, deterministic subset prefix, descriptor and exact program, CID, width and Unicode facts. The recipe uses the raw signed 16.16 italic-angle value. Hash matching only selects candidates for exact descriptor and byte comparison.

The six-uppercase-letter subset tag hashes the exact source face and ordered retained glyph IDs. Font resource names use canonical font ordinals. Lowering assigns these names to prepared glyph bodies and resource use from earlier run and ownership facts. The identity arena retains the derived material needed for equality and emission without retaining or copying a caller's full program.

The `font-leaves` evidence covers adversarial source order, shared placements, distinct fonts, and invalid descriptors, mappings, and metric plans. `scripts/check_fonts.py` verifies the complete emitted bundle and ownership. `scripts/check_font_renderers.py` independently renders the selected snapshots with the pinned engines.
