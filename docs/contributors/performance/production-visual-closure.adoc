= Visual compiler verification controls

Use the cases for the affected capability families in `tests/spec.json`.
Every family records positive and atomic negative output, decoded object
and structure checks, and deterministic work and allocation evidence.
The capability sections identify the matching opt-in reader matrix.

[#contributor-production-visual-closure-verification-contract]
== Verification contract

Run `./scripts/test.py --allocation-baselines` with the pinned compiler.
Use focused `--case` selectors where appropriate. Run
`./scripts/docs.sh` to check that emitted API documentation keeps
private object internals out of the public facade. Use
`scripts/check_gallery.py` to reproduce the runnable public examples.
Application authoring examples consume the package root, and checked
snapshots retain asset provenance in `assets/provenance.json`.
