= Ordered multiface output for advanced callers

`KernelShape.validate_advanced_selected` consumes the ordered
`Font.FaceRange` plan and once-parsed face inspections. Each shaped run
matches one selected cluster range and instance. The text, font-plan,
subset, CID, ToUnicode, resource, tagged-content and sealed-object
stages retain the instance identity without repeating coverage selection.

The `text-layout ordered multi-face advanced output` case in
`tests/spec.json` selects `[Latin, CJK, Latin]` for three graphemes.
The fixture uses U+0043, U+4E2D and U+00E9. It checks two sanitized
TrueType subsets, exact direct page-resource closure and separate
CID/ToUnicode maps. Direct reconstruction and PDFBox extraction
recover all three scalars in order. The invalid twin `MissingCoverage`
checks a Latin scalar itemized as `Hani` before the plan escapes.
The case metadata pins exact allocations, work and the two independent
renderer expectations.

See xref:contributor-layout.adoc#contributor-multiface-public-facade[ordered face selection through the facade].
