= Inter Latin shaping evidence

The facade shapes an eligible Inter Regular English paragraph with one
strictly loaded roc-font plan per document. The font identity is the
validated SHA-256 digest. Only printable ASCII and U+2192 use this path,
with one scalar per Unicode grapheme. The checked scalar API retains byte
offsets through substitutions. The adapter verifies one glyph per output
cluster and an exact partition of Unicode scalar and byte ranges, and checks
the trace's ligature classification. The same font-unit template serves
repeated occurrences at different sizes. The line cache separates shaped
and nominal uses of the same interned source. A paint-only scope shares
the shape while applying its own colour to the same cluster positions.

At a legal cut inside a cluster or one the shaper marks unsafe, preparation
isolates the legal spans and shapes each side. This bounded policy also
isolates potential cuts that happen to fit on one line. The final advances
are measured together with the existing Unicode break facts. The input cap
is 16,384 scalars per eligible paragraph. The provider sees at most two
passes of the source scalars, and its checked substitution budget applies
to each call. The pass counter counts those input scalars in the facade's
shaping work. Signed offsets use the same checked round-half-away-from-zero
conversion as positive advances, applying the sign after scaling magnitude.

The exact Inter and HarfBuzz pins are in
https://github.com/lukewilliamboswell/roc-pdf/blob/main/vendor/README.md[the dependency notices]. OpenType 1.9.1
https://learn.microsoft.com/en-us/typography/opentype/spec/gsub[GSUB]
and https://learn.microsoft.com/en-us/typography/opentype/spec/gpos[GPOS]
determine shape. ISO 32000-2:2020 9.10.3 and 14.9.4 govern the separate
`ToUnicode` and `ActualText` evidence. `AV` advances by 1273 and 1413 font
units. Disabling `kern` restores 1413 for `A`. The authors' `->` and `→`
both draw glyph 1805. Disabling `calt` leaves the first spelling as glyphs
1459 and 1517. The one-character spelling supplies the shared CID's
`ToUnicode` value, and the ligature's `ActualText` retains both original
source scalars. This also works when a wrapped literal-arrow line follows
the ligature's line.

The bounded adapter model exhausts 85 histories of at most three authored
pieces, including a ligature after an earlier multibyte occurrence and an
unsafe legal cut. Solve verifies that the production span length can be
subtracted without underflow and added back at ordered endpoints. The
structured fuzz target tests shaped widths at and around exact fit for four
cluster patterns and requires atomic rejection below minimum. The native
Linux smoke matched its four seed baselines and exercised 64 generated inputs.

The independent PDF checker recovers actual glyph positions, source text,
original paragraph ownership and colour. Its two mutation twins preserve PDF
structure while dropping a contributor from `ActualText` or one kerning
adjustment. The public report test verifies emitted bytes match ordinary
preparation. The scale pair expands from 6 to 42 wrapped fragments on one
and two pages. The allocation baseline on the pinned Roc dev backend
records 2,592 to 3,403 allocations and 6,194,773 to 8,028,722 requested bytes,
including both preparation paths and a separate two-line unsafe break.
The atomic budget case checks both buffered and chunked entry points.

Run the fixture group and independent checker from the repository root.

[source,sh]
----
./scripts/test.py --quick --allocation-baselines --group shaping
python3 scripts/check_inter_latin.py --self-test
----

Use `--harfbuzz` with the pinned local Python binding to replay the optional
differential. Local Arlington 1.30.2 and veraPDF 1.30.2 reviews passed for all
three PDFs, including explicit `4` and `ua2` and `wt1a` on the declared WTPDF
variant.
