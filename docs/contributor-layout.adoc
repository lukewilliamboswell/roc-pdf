Use the focused fixture group and independent checker named by the relevant contract. The xref:contributor-reference.adoc[contributor reference] describes the pinned tools and verifier controls. `tests/spec.json` records exact allocations and deterministic work under those pins, the allocated-byte reference for each target, and the expected PDF snapshots. Regenerate only reviewed baselines. Explain snapshot, work and count changes in terms of their architectural cause.
